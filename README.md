# Hand Bridge(sever part)

## 프로젝트 설명

### 프로젝트 개요

- 본 프로젝트는 외국인 청각장애인의 공항 이용 편의성을 높이기 위한 다국어 수어 번역 기반 공항버스 안내 시스템 개발을 목표로 합니다. 기존 수어 인식 서비스의 언어 및 상황별 맞춤 기능 부족 문제를 해결하여, 정보 접근성을 향상시키고 사회적 약자의 이동 편의를 증진하고자 합니다.

### 주요 목표
- 외국인 청각장애인의 언어 장벽 해소 및 정보 접근성 향상
- 공항 이용 시 발생하는 불편함 최소화
- 사회적 약자의 이동 편의 증진
- 수어 인식 서비스의 언어 및 상황별 모델 제공을 통한 정확도 향상

##  주요 기능

### 수어(handML)

- **[동작 인식](./docs/action.md)**: 실시간으로 캡처된 손의 랜드마크 시퀀스를 처리하여 특정 동작을 예측하고 식별합니다. 클래스는 랜드마크의 이력을 저장하기 위해 deque를 사용하며, 머신러닝 모델을 사용하여 이를 미리 정의된 동작으로 해석합니다.

### 언어(multiLanguage)

- **다국어 처리**: gettext, '.po'파일을 통해 중국어(zh_Hans), 영어(en), 한국어(ko)를 지원합니다.
- **엔드 포인트**: /multiLanguage/choiceLanguage 엔드포인트를 통해 사용자가 원하는 언어를 선택할 수 있습니다.

###  공항버스 안내 시스템(airportBus)

- **탑승장 찾기**: 수어로 버스 번호를 입력하여 해당 버스의 탑승장 위치와 안내를 받을 수 있습니다.
- **버스 시간표 조회**: 수어로 버스 번호를 입력하여 해당 버스의 시간표를 확인할 수 있습니다.
- **티켓 구매**: 수어로 원하는 버스 노선, 시간, 인원수를 선택하여 티켓을 구매할 수 있습니다. 출발 지역을 선택하여 버스를 검색할 수도 있습니다.
- **환불**: 수어로 환불 요청을 하고, 필요한 경우 추가 질문을 통해 안내를 받을 수 있습니다.

- **[전체 서비스 흐름](./docs/bus.md)**

###  WebSocket(WebSocket)

- 양방향 소통을 위해 javascript, flutter와 모두 연결하여 통신합니다.
- **엔드 포인트**: /ws/js, /ws/flutter 엔드포인트를 통해 클라이언트와 서버 간의 양방향 통신을 지원합니다.

##  기술 스택

- **언어**: Python, JavaScript
- **Backend**: Django, Django REST framework, Django Channels
- **프론트엔드**: HTML, CSS, JavaScript, Bootstrap, tailwindcss
- **데이터베이스**: SQLite3
- **머신러닝**: Keras(딥러닝 모델)
- **컴퓨터 비전**: Mediapipe
- **기타**: WebSocket, gettext, selenium
