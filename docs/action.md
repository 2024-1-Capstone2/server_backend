# handML

## 기능 

- 사용자의 손 관절 데이터를 실시간으로 분석하여 수어 동작을 인식하고, 인식된 결과를 웹 및 모바일 클라이언트에 전달합니다.

### 주요 기능

- **상황별 모델 로드**: 다양한 상황에 맞는 최적의 딥러닝 모델을 선택하여 사용합니다.
- **손 관절 데이터 처리 및 수어 동작 인식**: handML/api/hand-data 엔드포인트를 통해 JavaScript MediaPipe에서 얻은 손 관절 데이터를 전처리하고, 딥러닝 모델을 통해 수어 동작을 예측합니다.
- **실시간 정보 전달**: Django Channels를 활용하여 인식된 수어 동작 정보를 웹 및 모바일 클라이언트에 실시간으로 전달합니다.


### 핵심 특징

- **다국어 및 상황별 맞춤 인식**: 한국 수어, 중국 수어 등 다양한 언어와 상황에 따른 정확한 수어 동작 인식을 지원합니다.
- **실시간 양방향 통신**: Django Channels를 통해 웹 및 모바일 클라이언트와 실시간으로 데이터를 주고받습니다.
- **효율적인 자원 관리**: 싱글톤 패턴을 적용하여 시스템 자원을 효율적으로 관리합니다.
